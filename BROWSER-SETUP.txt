================================
BROWSER SOCKS5 PROXY SETUP GUIDE
================================

The proxy server now properly handles domain names for routing!
Just configure your client to use SOCKS5 proxy at 127.0.0.1:1080

CURL
====
Both options now work (DNS resolution disabled in proxy server):
   curl --socks5 127.0.0.1:1080 http://example.com
   curl --socks5-hostname 127.0.0.1:1080 http://example.com


FIREFOX
=======
1. Go to Settings → General → Network Settings → Settings
2. Select "Manual proxy configuration"
3. Set SOCKS Host: 127.0.0.1, Port: 1080
4. Select "SOCKS v5"
5. (Optional) Check "Proxy DNS when using SOCKS v5" for extra privacy
6. Click OK


CHROME/CHROMIUM
===============
Option 1 - Command Line:
   chromium --proxy-server="socks5://127.0.0.1:1080"

Option 2 - Extensions:
   Install "Proxy SwitchyOmega" extension:
   1. Create new profile
   2. Protocol: SOCKS5
   3. Server: 127.0.0.1, Port: 1080


SYSTEM-WIDE (Linux)
===================
For terminal applications:
   export ALL_PROXY=socks5://127.0.0.1:1080


TESTING
=======
Run this script to verify routing:
   ./test-routing.sh

You should see in logs:
   🔵 SOCKS5: New connection request to example.com:80 (domain)
   🔀 ROUTING: example.com:80 → OUT [out-us] (tag: 'us')
   ✅ OUT EXIT: Connected from OUT node


HOW IT WORKS
============
The proxy server disables DNS resolution in the SOCKS5 library
(config.set_dns_resolve(false)), which preserves domain names
for tag-based routing decisions.
